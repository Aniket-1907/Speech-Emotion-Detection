SPEECH EMOTION DETECTION — COMMAND CHEAT SHEET (Windows)
========================================================

Project root:
    C:\projects\Speech-Emotion-Detection

Run project commands from the project root unless stated otherwise.
Use the same Python environment for installation, training, and running the API.

1. OPEN PROJECT
---------------
CMD:
    cd /d C:\projects\Speech-Emotion-Detection

PowerShell:
    Set-Location C:\projects\Speech-Emotion-Detection

2. CREATE / ACTIVATE VIRTUAL ENVIRONMENT (recommended)
------------------------------------------------------
Create once:
    py -3.12 -m venv .venv

CMD:
    .venv\Scripts\activate.bat

PowerShell:
    .\.venv\Scripts\Activate.ps1

If PowerShell blocks activation, use CMD or run:
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    .\.venv\Scripts\Activate.ps1

3. INSTALL DEPENDENCIES
-----------------------
If requirements.txt exists:
    python -m pip install --upgrade pip
    python -m pip install -r requirements.txt

For the API and browser-audio conversion, ensure these are installed:
    python -m pip install fastapi uvicorn python-multipart imageio-ffmpeg

4. SCAN DATASETS / CREATE MANIFEST
----------------------------------
From the project root:
    python -m src.check_dataset

The scanner should create/update:
    data\manifest.csv

If RAVDESS is not recognized, check the folder structure and filename rules.
The current scanner may only include audio-only speech files starting with 03-01-.

5. TRAIN THE MODEL
------------------
    python -m src.train

If your train.py supports CLI arguments:
    python -m src.train --epochs 40 --batch_size 32

If unsure which arguments are supported:
    python -m src.train --help

Expected checkpoint:
    artifacts\best_model.pt

Train before starting the API if the checkpoint does not exist.

6. EVALUATE
-----------
    python -m src.evaluate

Review the metrics and report printed/generated by your current evaluate.py.

7. START BACKEND API
--------------------
Terminal 1, from the project root:
    python -m uvicorn src.api:app --host 127.0.0.1 --port 8000

Keep this terminal open.

API health:
    http://127.0.0.1:8000/health

Interactive API docs:
    http://127.0.0.1:8000/docs

Health should report model_loaded=true. If false, train the model and check artifacts\best_model.pt.

8. START HTML/CSS/JS FRONTEND
-----------------------------
Terminal 2, change to the folder containing index.html, styles.css, app.js.
Example path; change it if yours differs:
    cd /d C:\projects\speech_emotion_local_ui

Start static server:
    python -m http.server 5500

Open in browser:
    http://127.0.0.1:5500

In the UI, API base URL should be:
    http://127.0.0.1:8000

The UI posts to /predict using multipart field "file".
If CORS blocks the request, configure CORS_ORIGINS as below.

9. CONFIGURE CORS WITHOUT CHANGING CODE EACH DEPLOYMENT
-------------------------------------------------------
CMD, current terminal session:
    set CORS_ORIGINS=http://127.0.0.1:5500,http://localhost:5500

PowerShell, current terminal session:
    $env:CORS_ORIGINS = "http://127.0.0.1:5500,http://localhost:5500"

In a hosting provider's environment variables, set CORS_ORIGINS to the actual deployed frontend origin, for example:
    CORS_ORIGINS=https://your-real-frontend-domain.example

Replace the example with your actual origin. Restart the API after changing the variable.

10. TEST A PREDICTION
---------------------
- Open the frontend.
- Upload a WAV first for the simplest test.
- Click Analyze emotion.
- If microphone recordings fail with "Unsupported audio format", ensure src\api.py supports .webm and converts it to WAV before feature extraction.
- Inspect API errors at http://127.0.0.1:8000/docs and in the Uvicorn terminal.

11. COMMON ERRORS
-----------------
"'uvicorn' is not recognized":
    python -m pip install uvicorn
    python -m uvicorn src.api:app --host 127.0.0.1 --port 8000

"No module named fastapi":
    python -m pip install fastapi

"Form data requires python-multipart":
    python -m pip install python-multipart

"NameError: name 'os' is not defined":
    Add this to src\api.py:
        import os

"Unsupported audio format":
    Browser recordings are often .webm. Install:
        python -m pip install imageio-ffmpeg
    Ensure the API converts the upload to WAV before extract_feature().

"Failed to fetch":
    Check the API is running, URL is http://127.0.0.1:8000, and CORS allows the UI origin.
    Open browser DevTools (F12) > Console for the exact error.

"POST /predict/predict 404":
    The UI API base URL must be http://127.0.0.1:8000, WITHOUT /predict.

"Model checkpoint not found":
    Run training and check artifacts\best_model.pt exists.

12. QUICK START WHEN TESTING AGAIN
----------------------------------
Terminal 1:
    cd /d C:\projects\Speech-Emotion-Detection
    .venv\Scripts\activate.bat
    python -m uvicorn src.api:app --host 127.0.0.1 --port 8000

Terminal 2:
    cd /d C:\projects\speech_emotion_local_ui
    python -m http.server 5500

Then open:
    http://127.0.0.1:5500

Rescan/retrain when adding data or creating a new model checkpoint.
Restart the API after replacing best_model.pt so the new checkpoint is loaded.
