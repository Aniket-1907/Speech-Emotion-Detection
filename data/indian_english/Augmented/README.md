# Emotion Voice Samples Dataset – Augmented 🎧

This dataset is built by augmenting the original recordings to increase size and variability. Augmentation techniques applied include pitch shifting, time stretching, noise injection, and volume adjustment—resulting in a richer training set.

## 📂 Directory Structure

```text
Emotion-Voice-Samples-Augmented/
├── Happy/     (augmented files per emotion)
├── Sad/       (augmented files per emotion)
├── Angry/     (augmented files per emotion)
└── Neutral/   (augmented files per emotion)
```

## 🛠️ Augmentation Techniques
### Applied to each original sample:

- Pitch Shifting — ±2 semitones

- Time Stretching — speed variations (±10%)

- Noise Injection — light Gaussian/background noise

- Volume Adjustment — ±3 dB


Filenames are zero-padded (e.g., `001.wav`, `002.wav`, …), and each unique sample is a distinct audio file.
